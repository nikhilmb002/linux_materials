How to open file ?

	Using open sys call

	int open(const char* path, int flags);

	on success fd returned.
	on failure -1.

	
	flags
	-----

	* Mandatory
	* Optional 

	Mandatory
	---------
	
	* O_RDONLY 
	* O_WRONLY
	* O_RDWR


	optional
	--------

	* O_CREAT
	* O_EXCL
	* O_APPEND
	* O_TRUNC


	03_fd.c

	fopen("temp", "w");	// open it for write mode, if file not there
				// create, already there truncate

	open("temp", O_WRONLY);	// if already file exists, then only it opens

	open("temp", O_WRONLY | O_CREAT | O_TRUN); // if already file it trunctes and then open, if doesn't exists then create new one

	open sys call return file descriptor
	
	open("temp", O_WRONLY | O_CREAT | O_TRUNC, 0664);
						     |
						     |
						     ----> file permissions

	0664 -> it will effect file created using O_CREAT flag. If file already available then mode values are passed.


	file permissions : mode & ~(umask)

			  0664  =  110 110 100
						&
			 ~0002  =  111 111 101 
			------------------------
				   110 110 100 
                                   rw- rw- r--



	fopen("temp", "r"); -> open("temp", O_RDONLY);
	
	fopen("temp", "w+"); -> open("temp", O_RDWR | O_CREAT | O_TRUNC, 0664);

	fopen("temp", "r+"); -> open("temp", O_RDWR);

	fopen("temp", "a"); -> open("temp", O_WRONLY | O_CREAT | O_APPEND, 0664);

	fopen("temp", "a+"); -> open("temp", O_RDWR | O_CREAT | O_APPEND, 0664);

	

* Each and every mode of fopen() there is a open sys call

* But what ever open() sys call is doing (file operations) all operations not possible with fopen(). 	
	

read()
------

attempts to read upto count bytes from file descriptor fd into the buffer starting at buf.

if count is 0, read returns zero and has no other results. if count is greater than SSIZE_MAX, the result is unspecified.
