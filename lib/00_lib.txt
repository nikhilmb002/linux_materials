* A function f() is said to be statically linked function if it is defined inside the executable file 

* A function f() is said to be dynamically linked function if it is  not defined the executable file but it is used.

* An executable file a.out is said to be statically linked exe file if all function defnitions available with executable file.

* An executable file is said to be dynamically linked executable file if there exist at least one function which is going to be linked in later stage.
